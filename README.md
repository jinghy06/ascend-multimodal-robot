# 基于昇腾平台的多模态交互自主跟随与物品抓取机器人

以 Huawei Atlas 200I DK A2 为边缘计算平台，结合 ROS 2、视觉感知、语音交互和机械臂策略，探索人物跟随、激光点指引导航及物品抓取。

本仓库为 2026-10-30 整理的公开快照，包含已有代码、方案和测试证据。整机功能仍在集成；设计目标、调研结论和已经完成的实测应分别理解。

## 已有证据与边界

- 已有 SmolVLA 在 Ascend 310B 上的推理及 CPU / NPU 数值对照。
- 原工作配置暖机推理约 4.19 秒；单相机、低分辨率、减少迭代步数的快速配置约 0.68 秒，但动作输出差异明显，不能视为同质量替代或抓取成功证明。
- 完整语言骨干恢复的本地测试和中文意图分类结果保存在测试目录；生成文本不等于可靠理解控制指令。
- ROS 内存测量脚本存在不代表已取得板端测量结果；无原始结果支持的项仍是待验证。
- 机器人控制意图优先关注“跟着我走”“去红点那里”“捡起红色方块”等任务。规则、白名单和未知指令处理用于任务路由，模型输出不能直接作为电机控制量。
- `voice_control` 包中的代码与 PC 测试可独立使用；真实录音效果、ROS 集成和整机抓取仍需各自验收。

## 开发入门

仅运行语音包的纯逻辑测试，不需要下载模型或连接机器人：

```bash
cd voice_control
python -m venv .venv
# Linux / macOS
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install numpy pyyaml pytest
python -m pytest tests/test_command_rules.py tests/test_llm_parser.py tests/test_router.py -q
```

完整语音依赖、下载与使用方法见语音包 README。模型从其原始来源自行下载，须遵守各自的许可与使用条件。

Atlas 实验脚本保留了当时的实验目录及 CANN / Python 版本约定。执行前需按自身环境调整路径、安装匹配的 `torch` / `torch_npu` / CANN，并准备模型；这不是一键部署整机的安装包。脚本测试使用合成图像与归一化状态，不发送真实机械臂动作。

演示文稿生成脚本需要单独提供兼容的 `@oai/artifact-tool`、Python 及演示工具环境。仓库已包含生成的 PPTX / DOCX，可直接阅读，不必运行生成器。
