# SmolVLA 与昇腾部署参考资料

检索日期：2026-10-20。以下区分硬件与模型，外部作者报告不作为本机测量值。

| 来源 | 对应平台/模型 | 可借鉴内容 | 对本项目的限制 |
|---|---|---|---|
| [Hugging Face SmolVLA 文档](https://huggingface.co/docs/lerobot/smolvla) | 官方 SmolVLA / LeRobot | 模型使用、数据采集与训练流程 | 官方基础权重跑通不等于已适配本项目机械臂 |
| [lerobot-on-ascend](https://github.com/hexchip/lerobot-on-ascend) | Orange Pi AIpro 20T / 昇腾 310B / ACT | Python、PyTorch、torch_npu、CANN 配套；机械臂集成方法 | 演示对象是 ACT，不能作为 SmolVLA 已在当前板上跑通的证据 |
| [smolvla-base-npu](https://ai.gitcode.com/gcw_C8PI9e90/smolvla-base-npu) | 昇腾 910 64GB / CANN 8.5.1 / torch 2.9 | 本地离线加载；bucketize 兼容；同一确定性噪声的 CPU/NPU 对照 | 作者报告的亚秒耗时来自 910，不能移用到 310B4 与 3.5GB 内存环境 |
| [SO101 抓橙子适配记录](https://ai.gitcode.com/mixail/smolvla-so101-pick-orange) | 昇腾 910_9362 / CANN 8.5.1 | 关闭重复的骨干权重加载，只读骨干配置与分词器；完整策略权重加载 | 硬件、软件版本与本机不同 |
| [CANN UpsampleBilinear2d 源码与说明](https://gitcode.com/cann/ops-cv/tree/master/image/upsample_bilinear2d) | CANN 官方算子仓库 | 按具体产品核查算子支持范围 | 本机实测 resize 无法直接运行，先在 CPU 预处理；最新文档不替代旧 CANN 实测 |
| [MiniCPM-V on Ascend 310B](https://github.com/lvyufeng/minicpm-v-4.6-orangepi) | Orange Pi AIpro 20T / 310B / CANN 8.3.RC2 | CPU 图像预处理、C++/AscendC 推理和自定义算子方法 | 是另一种模型与专用引擎，不能直接拿来加载 SmolVLA |
| [IB_Robot](https://gitcode.com/openeuler/IB_Robot) | openEuler 机器人框架 | 推理服务与机器人控制解耦的工程结构 | 通用框架，不是当前板与权重的性能保证 |
| [Characterizing VLA Models across XPUs](https://arxiv.org/abs/2604.24447) | 多种 VLA 与 XPU，包含 310B | 异构端侧推理瓶颈与优化思路 | 论文的 310B 内存条件不同于本机，不能直接套用性能 |

本次已采用：完整策略权重只加载一次、骨干配置离线化、固定噪声 CPU 对照、NPU 同步计时、CPU 图像预处理、缺失融合算子的进程内兼容处理。

工程判断：先用本机的完整前向结果判断能否运行，再讨论精度、时延与机器人任务成功率。若要优化正式部署，可进一步评估匹配的 CANN/310B kernels 软件栈、静态图/OM 分段导出、视觉特征缓存与减少扩散步数；这些均需要独立验证，当前没有性能承诺。
